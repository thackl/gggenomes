# Resolve scalebar visual styling

Shared by the geom and theme defaults.

## Usage

``` r
scalebar_style(
  linewidth = NULL,
  colour = NULL,
  linetype = NULL,
  lineend = NULL,
  text_size = NULL,
  text_colour = NULL,
  family = NULL,
  fontface = NULL,
  tick_height = NULL,
  label_offset = NULL
)
```
